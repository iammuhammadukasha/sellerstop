# Cash Buyer Landing

Standalone "We Buy Houses for Cash" landing page with 3D hero and Framer Motion animations.

## Tech

- **Next.js 15** (App Router)
- **React Three Fiber** + **Drei** – 3D hero (house, coins, sparkles)
- **Framer Motion** – scroll and section animations
- **TypeScript**

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

This project is separate from the Nicholas Realty (probate/trust) site.
